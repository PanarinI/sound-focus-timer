## 1. Суть (Charter) — живая гипотеза, не контракт
(«пока не знаю» — ок; пересматривается на шаббате)
- **Что это:** CWS-расширение — фокус-таймер, где время сделано из звука. Генеративные звуковые
  сессии (WebAudio на устройстве, без файлов и стрима): вход «минута до» (плавное подведение к
  концентрации) → плато (звук охраняет поток стабильностью) → выход-«рассвет» (не будильник);
  палитра знает время суток. Позиция: «мягкий фокус» — против армии блокеров-наказателей.
  Аудитория: те, кому фокус надо ЗАЩИЩАТЬ, а не создавать.
- **Зачем / цель:** честный коммерческий запуск по методике студии (продукт CWS-дорожки app-studio;
  доход + серийная практика). Автор — первый пользователь (личная тяга = актив, не аргумент выбора).
- **Готово, когда:** **Веха 1 — опубликован в CWS** (закрывает форму «стройка»; дальше метаморфоза:
  организм линяет в продукт-ДНК). **Веха 2 (уже продукт) — 2000 юзеров** (порог разговора о
  монетизации по методике). Рабочее имя продукта для стора — не выбрано (задача вехи 1, с бронью).
- **Ограничения:** соло + Клод · бюджет ~$200–300, ориентир 1–2 недели до публикации · всё на
  устройстве (приватность by design, $0 инфры) · имя без слова «Pomodoro» (марка Чирилло) ·
  MVP без слежки за вкладками (права/модерация) · Игорь — вайб-кодер (объяснения по-человечески).
- **Не-цели:** не блокер сайтов (мы зовём, не запираем) · не библиотека звуков/лупов (звук
  генерируется, не проигрывается) · не «нейро-наука фокуса» с громкими клеймами · слежка за
  поведением («зов» из дрейфа) — НЕ в MVP, это v2 (но шину событий движка закладываем сразу) ·
  App Store-версия — не сейчас (на рост после вехи 2).

## 2. Столпы (живая карта)
Позвоночник: этот файл (суть+правила) · STATE.md (где мы) · DECISIONS.md (почему).
Органы (растут по нужде): `schemas/` — схемы сущности для автора (рождён при генезисе, правило
автора «визуализируй сущности»). Гипотезы будущих органов (НЕ созданы, ждут нужды):
SOUND.md — язык звукового дизайна (палитры·слои·арки), если знание начнёт копиться;
LAUNCH.md — путь публикации CWS по методике (листинг·скрины·ключи), ближе к вехе 1.
Досье ниши живёт в студии: `app-studio/research/sound_focus_timer_niche_report.{md,html}` (+ IDEAS.md).

## 3. Протокол роста — дыхание организма
- Вдох (старт сессии): читать этот файл → STATE → DECISIONS → нужные органы.
- Обмен веществ (всегда): любую входящую мысль направляй — устоявшееся/структурное → в столп;
  накапливающееся знание → в орган; сырое → держи в живом контексте. Всегда говори, куда положил.
- Рост: инфа повторяется и не влезает в столпы → предложи орган (имя+зачем), рождай с «да».
- Выдох (шаббат): обнови STATE; допиши «почему» в DECISIONS; поправь этот файл при смене сути/карты;
  пересмотри столпы (родить/слить/убрать); выдай «первое сообщение для новой сессии».
