## 1. Суть (Charter) — живая гипотеза, не контракт
(«пока не знаю» — ок; пересматривается на шаббате)
- **Что это:** CWS-расширение (**десктоп** — расширения не ставятся в мобильный Chrome) — **фокус-ТАЙМЕР,
  чьё время сделано из звука**. Якорь сути: *мягко вводит в фокус и бережно выводит — сопровождает, не наказывает.*
  Таймер = существительное (дверь спроса · деньги · идентичность); звук = его тело/душа/клин (**НЕ** шум-генератор
  с таймером сбоку — это park). Материал — **тёплый генеративный brown-ШУМ** (+pink-воздух +пространство +микро-дрейф;
  на устройстве; НЕ синусовый дрон). Сессия: вход «минута до» → плато → выход-«рассвет» (не будильник).
  Позиция: «мягкий фокус» против блокеров-наказателей. **Ядро — ADHD-взрослые** (звук функционален:
  возбуждение+маскировка); отстройка бьёт в ОБА их полюса — мягко ВВЕСТИ (трение старта) и не РАЗОРВАТЬ (гиперфокус);
  шире — все, кто ищет спокойный фокус.
  **Поверхность (07-12, рамка) — new-tab-ПОВЕРХНОСТЬ как MVP** (своя страница `chrome_url_overrides`, ноль host-прав,
  БЕЗ инжекта): уголёк+звук+таймер. floating-вынос (инжект content-script) и мир-таверна (обои/уют/накопление) —
  метаморфозы ПОТОМ, не MVP (метод: «кнопочки убивают активацию главной»; мир-дверь `aesthetic new tab` = 20 запросов).
  Орб = **уголёк-очаг** одного присутствия в двух проекциях: **new-tab=дом-пристанище · floating=вынос в работу**
  (один звук/состояние). Присутствие-**костёр** (незримое оберегающее; дышит · теплеет · голос=звук), **НАРАСТАЕТ**
  к полноте, в рассвете опадает. **Тап** = старт (дефолт 25) · **кручение** = своё время. Накопление = whiteboard-ritual
  автора (тепло мира, без вины/цифр). Глубина/«интереснее помодоро» = связка экст→апп (не раздувание таймера).
  Два слоя: **basic** (ядро) · **premium** (опыт). Полный фокус+душа+открытые узлы — в `STATE.md`.
- **Зачем / цель:** честный коммерческий запуск по методике студии (продукт CWS-дорожки app-studio;
  доход + серийная практика). Автор — первый пользователь (личная тяга = актив, не аргумент выбора).
- **Готово, когда:** **Веха 1 — опубликован в CWS** (закрывает форму «стройка»; дальше метаморфоза:
  организм линяет в продукт-ДНК). **Веха 2 (уже продукт) — 2000 юзеров** (порог разговора о
  монетизации по методике). Рабочее имя продукта для стора — не выбрано (задача вехи 1, с бронью).
- **Ограничения:** соло + Клод · бюджет ~$200–300, ориентир 1–2 недели до публикации · всё на
  устройстве (приватность by design, $0 инфры) · имя без слова «Pomodoro» (марка Чирилло) ·
  MVP без слежки за вкладками (права/модерация) · Игорь — вайб-кодер (объяснения по-человечески).
- **Не-цели:** не ЖЁСТКИЙ блокер-наказатель (мы зовём, не запираем; **mindful-мягкий блок — открытый узел v2**,
  см. STATE) · не библиотека звуков/лупов (звук генерируется, не проигрывается) · не «нейро-наука фокуса» с
  громкими клеймами · слежка за поведением («зов» из дрейфа) — НЕ в MVP, это v2 (шину событий закладываем сразу) ·
  App Store-версия — не сейчас (на рост после вехи 2).

## 2. Столпы (живая карта)
Позвоночник: этот файл (суть+правила) · STATE.md (где мы) · DECISIONS.md (почему).
Органы:
- `AUDIENCE.md` — кто пользователь (ядро · двери · конкуренты · функц. настройки vs красота). Рожд. 07-05.
- `schemas/` — схемы сущности для автора (product-essence · audience-portrait). Правило «визуализируй сущности».
- `lab/` — стенды выбора звука (`taste.html`, `taste2.html`) — верстак дегустаций. Рожд. 07-05.
- `extension/` — сам продукт (MV3). `engine.js` — движок: **Brown-ядро** + дирижёр фаз + arousal + tier
  basic/premium + гармонизация. **`orb.html`/`orb.js`** — НОВОЕ ядро-присутствие (орб нарастает · дышит · теплеет ·
  голос=звук; формо-независимо — поедет во floating). `sidepanel.*` — прежняя форма side-panel (**ОТЖИВАЕТ**).
  `dev.html` — стенд движка. `offscreen.*`+`popup.*` — вернём для floating-звука.
Гипотезы будущих органов (НЕ созданы, ждут нужды): SOUND.md — язык звукового дизайна, если знание
начнёт копиться отдельно от lab/DECISIONS; LAUNCH.md — путь публикации CWS, ближе к вехе 1.
Досье ниши живёт в студии: `app-studio/research/sound_focus_timer_niche_report.{md,html}` (+ IDEAS.md).

## 3. Протокол роста — дыхание организма
- Вдох (старт сессии): читать этот файл → STATE → DECISIONS → нужные органы.
- Обмен веществ (всегда): любую входящую мысль направляй — устоявшееся/структурное → в столп;
  накапливающееся знание → в орган; сырое → держи в живом контексте. Всегда говори, куда положил.
- Рост: инфа повторяется и не влезает в столпы → предложи орган (имя+зачем), рождай с «да».
- Выдох (шаббат): обнови STATE; допиши «почему» в DECISIONS; поправь этот файл при смене сути/карты;
  пересмотри столпы (родить/слить/убрать); выдай «первое сообщение для новой сессии».
