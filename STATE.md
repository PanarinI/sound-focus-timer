## Что построено (скелет `extension/`, 07-04)
- `engine.js` — движок mir (пад 55/82.4/164.8 + дыхание шума) + **дирижёр сессии**: ручей →
  собирание → ткань (углубление) → рассвет → ручей; пауза = ниточка. Абстракции master/depth/
  brightness → AudioParam через setTargetAtTime (**закон «нет резких границ»** — механически).
  Без chrome-зависимостей → переиспользуется в offscreen и dev-стенде. `this.GATHER/DAWN` можно
  ускорить (dev). Кламп длины = `GATHER+DAWN+10` (масштабируется с фазами).
- `offscreen.{html,js}` — непрерывный звук независимо от вкладок (условие «весь день»).
- `background.js` — маршрутизатор попап↔offscreen + иконка (рисуется OffscreenCanvas по глубине/яркости).
- `popup.{html,css,js}` — пульт: дышащая точка · одна кнопка по фазе · пресеты 25/50/90 · крутилки характера.
- `dev.html` — **стенд**: открыть в браузере, слышно всю арку (быстрый режим ~45с). Разрешения
  расширения — только `offscreen`+`storage` (чистейший листинг).
- **Проверено в preview (07-04):** AudioContext стартует, полный цикл фаз проходит без ошибок,
  все команды (пауза/продолжить/завершить/выключить) корректны, UI-обвязка двигает точку. Звук
  в headless-preview не слышен — слух за автором (dev.html / загрузка расширения).
