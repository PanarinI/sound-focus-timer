## ⚑ ФОРМАТ — РЕШЁН (07-17, с автором): лестница присутствия
Крест «в браузере vs поверх ОС» закрыт: ядро живёт В браузере (4/5 портретов) → **дом = Side Panel**, «поверх ОС» = опция. Форма перестала «ходить по кругу» (side-panel→floating→new-tab→PiP→side-panel за 07-10…17): выбирали не «лучшую поверхность» (её нет — **формат ⊥ дверь**, поверхность не ищут: floating 140 · PiP 30), а **сценарий**. Итог — 4 слоя:
1. **Иконка-уголёк в тулбаре** — база, ноль прав. Клик → открыть дом.
2. **Дом = Side Panel** — весь жар + богатое (**кручение · настройки · угли**). Там мы хозяева пикселей.
3. **Язычок-закладка у края страниц** (Merlin-паттерн, реш. автора 07-17) — **живой отблеск**: уголёк дышит/зреет/пульсирует статусом сессии, клик → открывает дом. **НЕ полный орб** (полный орб на краю = floating, дом растворяется) — богатое в доме, на краю манящий отблеск.
4. **PiP** — опция «поверх всех окон» для вне-браузера (Тео в IDE).
**Права язычка — НЕ ред-флаг** (факт-чек канона `knowledge-base/module-3/3.6-publish-cws.md:152`: host permissions = штатный пример обоснования «show extension action button on any website»; запрет один — не просить прав сверх функционала). Уголёк МОЖЕТ висеть с 1-й секунды (**required host**, как Sider/Grammarly — норма класса). Клин переформулирован: не «ноль прав», а **«права прозрачны, только ради присутствия — не следим»** (content-script рисует орб, не читает страницу). `optional_host` — теперь опция (чистая установка ценой пробуждения), не обязанность.
**Обёртка дома РЕШЕНА (07-17, автор «однозначно»): нативная Chrome Side Panel** — не накрывает контент (Chrome ужимает страницу), чисто/надёжно/везде; красотой слитного перетекания язычок→дом жертвуем (смягчение: язычок анимирует «свет ушёл вправо» при выезде панели). Язычок-отблеск = наш инжект (host-права). Механизм «клик язычка → open дом» 🔶 (`sidePanel.open()` требует user-gesture — проверить на сборке). New-tab-красота — опция v1.x.
**Детали образа (в MECHANICS при сборке — после глаз):** язычок = «свет из-под двери» как ОЩУЩЕНИЕ (тёплая планка + световая щель, НЕ буквальная дверь-иллюстрация); динамика сессии на язычке = **свет крепнет** (яркость + чуть ширины), размер стабилен (не лезет на контент); фаза = цвет, дыхание = пульс. Кольцо: **чёрточку-риску 12 убрать** — ноль держит ручка-огонёк (в покое на 12) + верх дуги (в сессии); один огненный язык (дуга + огонёк-ручка). Запас: ноль теряется → тёплая насечка в тон, не чёрточка.
