## Фокус инструмента (якорь — держать на виду)
> **Фокус-ТАЙМЕР, чьё время сделано из тёплого звука: мягко вводит в фокус и бережно выводит — сопровождает, не наказывает.**

Таймер = существительное (дверь спроса · деньги · идентичность). Звук = его тело/душа/клин. **НЕ** шум-генератор с таймером сбоку (это 1-я итерация = park). Сверено по досье 07-11: двери спроса таймерные (`pomodoro` 135k · `25 minute timer` 90.5k), `pomodoro timer with music` пустой (110). → **Тап = запуск сессии-таймера** (дефолт **25** — их ищут), завод кольцом = опция. «Просто шум без времени» = приятная тень, не главный вход.

## Душа орба (решено 07-11)
**Незримое оберегающее ПРИСУТСТВИЕ** — не персонаж, не глаз, не питомец. «Костёр, у которого сидишь спиной»: орб = отблеск/тепло/дыхание/голос(звук) незримого, что оберегает ТЕБЯ (забота направлена на пользователя, не он ухаживает). Апофатика = сосуд для проекции (каждый вкладывает своё).
- Три «нельзя»: не являть существо · не давать взгляд (=слежка, бьёт по приватности) · не заставлять заботиться о нём (лишний долг = вина, наш враг).
- Три «да»: дышит · теплеет с тобой · говорит звуком. Всё медленно, без событий.

## Что построено и работает (в файлах)
- **`extension/engine.js`** — движок (Brown-ядро + дирижёр фаз + arousal + tier basic/premium + гармонизация). Крутилки energy·masking·volume·harmony. **Фикс 07-11:** рассвет `master = 0.5·(1−easeInOut(p))` — звук истончается синхронно со сдуванием орба.
- **`extension/orb.html` + `orb.js`** — НОВОЕ ядро-присутствие (стенд, формо-независимо — поедет во floating). Орб **НАРАСТАЕТ** к полноте (рост по ПЛОЩАДИ = равномерное наполнение; дыхание фиксированное 7s; жар костра — тёплая палитра, уголёк→пламя), в рассвете **ОПАДАЕТ** в уголёк. Метка-ноль (золотая отсечка на 12ч = откуда/куда). Управление: **крути кольцо** = выставить время (дуга застывает) · **тронь орб** = старт · **ещё раз** = выкл (плавный выдох). Без ⏻, без надписей-ярлыков. Время = МИНУТЫ (галка «быстрый» = секунды для стенда).
- `extension/sidepanel.*` — прежняя форма side-panel (**ОТЖИВАЕТ** при переезде во floating; не удалять до Фазы 2). `dev.html` — стенд движка. `offscreen.*`+`popup.*` — вернём для floating-звука.
- `AUDIENCE.md` — + уточнение отстройки (два полюса ADHD) + наука (возбуждение/маскировка). `schemas/` · `lab/taste2.html`.
