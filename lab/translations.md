**Паттерн выверен на 7 языках (DE·ES·PT·FR·IT·JA·ID):** дверь = **POMODORO**, «фокус/концентрация» пусто везде (Fokus 90 · concentración 0 · de foco 0 · 集中 320 · timer fokus 0). Формула имени: **`[локальный pomodoro-ключ] - Minimalist Timer`**.
- Порядок слов: романские → `Timer/Temporizador/Minuteur Pomodoro`; германские/сканд. → `Pomodoro Timer`.
- Нюанс: слово «timer» интернационально — FR/IT/ID/JA берут англ. «timer» в pomodoro-ключе (не локальный minuteur/temporizador). Значит `Pomodoro Timer`/`Timer Pomodoro` работает почти везде.
- Ловушки: IT `pomodoro` соло = помидор (только составное); generic timer/minuteur/temporizador огромны (100k+), но слишком широки под наш продукт.
