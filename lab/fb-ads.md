## Рамка: сколько можно потратить

✅ Канон `4.1:22-26`: платный толчок делается ОДИН раз после публикации, типично **$30–150**
(100–300 установок), **выше $300 не тратить**, FB останавливают через **3–5 дней**.
Потолок считается по ВСЕЙ рекламе вместе, не по каждому каналу.

**Факт на 2026-08-22:** Яндекс Директ съел суммарно **11 700 ₽ ≈ $130–146** с 28.07 (идёт непрерывно).
Значит канонная вилка первого толчка уже выбрана, до жёсткого потолка остаётся **≈ $150**.
FB-тест на **$30–50 / 3–5 дней** в рамку влезает; это уже не «первый толчок», а тест второй площадки
(канон `4.1:50` рекомендует минимум 1 площадку, в идеале протестировать 2).

**Зачем FB, если Яндекс работает.** НЕ ради Tier-1 — канон `4.1:14-20` прямо запрещает переплачивать
за Tier-1-трафик. Причина в цене: канонная вилка **$0.03–0.10 за инсталл**, у нас по замеру 08-06 —
**95 ₽ ≈ $1.19**, то есть в 12–40 раз дороже. Проверяем, даст ли FB дешёвый объём.
⚠️ Часть разрыва — не канал, а конверсия листинга 11.3 % при норме 15–30 %. Она ударит и по FB.

## Тексты (канон `4.3:44-52`)

В FB инициатива у НАС: человек продукт не искал. ✅ «о SEO НЕ думаем» — только чтобы заметили,
поняли и захотели поставить. Чем банальнее, тем лучше. Язык — английский (целимся в дешёвые страны,
где английский — рабочий язык ленты). 🔶 RU-вариант имеет смысл, только если отдельно целиться в СНГ.

**headline** (≤1 строки, ✅ канон: «просто название продукта»)
```
Minimalist Timer
```

**primary text** (≤2 строк — суть + одно преимущество; ✅ канонная формула «Простой &lt;название&gt;.
Работает в 2 клика прямо в браузере»)
```
A simple focus timer with warm brown noise.
Works in 2 clicks, right in your browser.
```

**description** (≤1 строки)
```
No ads, no account, no extra tab.
```

⚠️ Следим, чтобы не обрезалось в предпросмотре FB.
🔶 Слово `free` намеренно не взято: канон запрещает его для Google-модерации (`4.3:70`), для FB запрета
нет, но смысл «бесплатно» и так несёт `No ads, no account`.

## Что такое «интересы»

Ярлык, который FB сам вешает на человека по его поведению (что лайкал, на что кликал). В настройке
группы объявлений есть поле **Detailed Targeting**: вписываешь слово — FB показывает, есть ли такой
ярлык и сколько под ним людей. Канон `4.3:66`: **одна группа БЕЗ интересов** (FB сам ищет, кому
показать) и **вторая С интересами по тематике** — потом сравниваешь цену клика. Если широкая
дешевле, интересы не нужны.

Кандидаты — вписывать в поле по одному и брать те, что реально нашлись (🔶 весь список не проверен,
таксономия FB меняется):
- Productivity · Time management · Study skills
- Pomodoro Technique · Notion · Todoist (прокси на продуктивную публику)
- Meditation · Mindfulness · White noise
- Google Chrome (без него расширение не поставить)

🔶 **ADHD скорее всего не найдётся** — Meta убрала таргетинг по health-категориям в 2022. Проверить в
поле; если нет — не искать обход, это ядро аудитории, но не единственная дверь.

## Структура кампании (канон `4.3:64-68`)

```
Кампания — оптимизация по КЛИКАМ
├── Группа 1 «broad» (без интересов)
│   ├── объявление A — квадрат 2048×2048
│   └── объявление B — прямоугольник 1280×800
└── Группа 2 «interests» (интересы по тематике)
    ├── объявление A — квадрат 2048×2048
    └── объявление B — прямоугольник 1280×800
```

🔶 **Перевод на сегодняшний интерфейс** (курс писался раньше): цель кампании = **Traffic**,
оптимизация = **Link clicks** (не Landing page views — на карточку CWS свой пиксель не поставить).

🔶 **Только десктоп.** В FB-блоке канона этого нет, но в Google- и Яндекс-блоках канон ставит
мобильным **−100 %** («с них не смогут установить расширения», `4.3:76`). В FB то же самое делается
в Placements → **Devices: Desktop only**. Без этого дешёвый трафик придёт с телефонов и деньги уйдут
в ноль — в бедных странах лента почти вся мобильная. Это самая дорогая ошибка из возможных.

🔶 **География: Worldwide, кроме Tier-1.** Прямо из `4.1:14-20` (дешёвые страны, живой трафик из любой
локации поднимает ранжирование по миру). США/ЕС не целим намеренно.

## Порядок запуска — чеклист

1. **Facebook Page** (✅ `4.3:12-18`) — без неё рекламу не настроить.
   `facebook.com/pages/creation` → простое имя, категория, описание → контрастная аватарка (её видно
   в каждом объявлении) → 1–2 поста о продукте (никто не читает, нужны для модерации FB).
2. **Бизнес-аккаунт** (✅ `4.3:20-27`) — `business.facebook.com/select` → подтвердить почту →
   привязать Page → создать **Ad Account** → добавить себя с максимальными правами.
3. **Оплата** — зарубежная карта; **часовой пояс тот же**, что в Ad Account.
4. **Кампания** — `adsmanager.facebook.com` → Traffic / Link clicks → бюджет **$8–10/день**.
5. **Группы и объявления** — по схеме выше; в каждое объявление свой креатив и своя UTM-ссылка.
6. **Placements** → Desktop only (🔶 см. выше).
7. **Проверить предпросмотр** — не обрезаются ли тексты.
8. **После запуска — смотреть комментарии** (✅ `4.3:72`): скрывать «вирус/скам». Канон:
   «когда хейтеры строчат, адекватные молчат» — хейт роняет CTR и поднимает цену клика.
9. **Остановить на 3–5 день** (✅ `4.3:74`) и сравнить с Яндексом: цена клика, клик→установка.

## Что мерить

- **цена клика** — против яндексовских 9.28 ₽ (замер 08-04);
- **клик → установка** — против наших 9.7 % и канонных 15–30 % (`4.3:46`);
- **какая группа дешевле** — broad или interests (ради этого и две группы);
- **какой креатив** — по `utm_content` (square / rect).

Установки видны только глазами в дашборде CWS: программного доступа у стора нет (`STATE.md`).
